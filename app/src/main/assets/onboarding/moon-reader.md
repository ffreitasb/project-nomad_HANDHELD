# Moon+ Reader — Guia de Primeiro Uso

**O que é:** leitor de e-books para Android com suporte a EPUB, PDF, MOBI, CBZ e outros formatos. 100% offline para arquivos locais.

## Primeiro uso

1. Instale pela Play Store.
2. Copie seus e-books para a pasta `/Documents/Books/` (ou qualquer pasta de sua preferência).
3. Abra o app → **Minha Estante** → **Importar livros** → selecione a pasta.
4. Os livros aparecem na estante e ficam acessíveis offline.

## Onde encontrar livros gratuitos para download prévio

| Fonte | Tipo de conteúdo |
|---|---|
| [Project Gutenberg](https://gutenberg.org) | Clássicos, domínio público |
| [Standard Ebooks](https://standardebooks.org) | Versões refinadas do Gutenberg |
| [OpenLibrary](https://openlibrary.org) | Acervo amplo (empréstimo) |

## Livros recomendados para o kit de sobrevivência

- **Where There Is No Doctor** — guia médico para áreas remotas (disponível em PDF gratuito)
- **SAS Survival Handbook** — manual de sobrevivência
- **The Anarchist Cookbook of Survival** — técnicas de campo

## Onde ficam os dados

Os livros ficam onde você os colocou. O Moon+ Reader apenas lê arquivos locais — não cria cópias.

## O que funciona 100% offline

- Leitura de todos os formatos suportados
- Marcadores e anotações
- Ajuste de fonte, tema, brilho

## O que NÃO funciona offline

- Integração com bibliotecas online (OPDS, Calibre server remoto)
- TTS (Text-to-Speech) depende do mecanismo do sistema, que pode precisar de internet na primeira vez
