# Organic Maps — Guia de Primeiro Uso

**O que é:** mapa offline leve e rápido, baseado no OpenStreetMap. Sem anúncios, sem rastreamento. Excelente para trilhas, ciclismo e uso urbano simples.

## Diferença em relação ao OsmAnd

| | Organic Maps | OsmAnd |
|---|---|---|
| Interface | Mais simples | Mais complexa |
| Trilhas / trekking | ✅ Muito bom | ✅ Muito bom |
| Navegação turn-by-turn | ✅ Básica | ✅ Completa |
| Edição de favoritos | ✅ | ✅ |
| Camadas de dados extras | ❌ | ✅ (curvas, transporte) |
| Tamanho do app | Menor | Maior |

**Recomendação:** Organic Maps para mobilidade urbana e trilhas. OsmAnd para viagens longas com navegação complexa.

## Primeiro uso

1. Instale pela F-Droid ou Play Store.
2. Abra o app → toque no ícone de **Download** (seta para baixo).
3. Selecione **Brasil** → escolha seu estado.
4. Aguarde o download.

## Onde ficam os dados

`Android/data/app.organicmaps/files/`

## O que funciona 100% offline

- Visualização de mapas com ruas, trilhas, POIs
- Navegação básica a pé, bicicleta e carro
- Marcadores e favoritos locais
- Busca de endereços offline

## Estimativa de espaço

Mapas estaduais variam entre 50 MB e 500 MB dependendo da região.
