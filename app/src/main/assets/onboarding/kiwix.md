# Kiwix — Guia de Primeiro Uso

**O que é:** leitor offline de conteúdo enciclopédico via arquivos ZIM. Funciona 100% sem internet após o download dos arquivos.

## Primeiro uso

1. Instale o Kiwix pela F-Droid ou Play Store.
2. Abra o app → toque em **Biblioteca** → **Baixar conteúdo**.
3. Selecione os arquivos ZIM desejados (ver conteúdo recomendado abaixo).
4. Aguarde o download — os arquivos ficam salvos no armazenamento interno.

## Onde ficam os dados

Os arquivos ZIM ficam em `Android/data/org.kiwix.kiwixmobile/files/` ou no caminho que você escolher ao baixar.

## O que funciona 100% offline

- Leitura de todos os artigos incluídos no ZIM baixado
- Busca interna
- Links entre artigos

## O que NÃO funciona offline

- Download de novos ZIMs (precisa de internet)
- Atualização de conteúdo existente

## Estimativa de espaço

| Conteúdo | Tamanho |
|---|---|
| Wikipedia PT-BR (artigos principais) | ~2 GB |
| Wikipedia — Medicina | ~1 GB |
| Gutenberg — Survival guides | ~200 MB |
