# Khan Academy — Guia de Primeiro Uso

**O que é:** plataforma de educação gratuita com vídeos e exercícios de matemática, ciências, história e mais. Permite baixar vídeos para uso offline.

> ⚠️ **Atenção:** apenas **vídeos** podem ser baixados para uso offline. Exercícios interativos precisam de internet.

## Primeiro uso

1. Instale pela Play Store.
2. Crie uma conta (necessário para salvar progresso) — **faça isso com internet**.
3. Navegue até o conteúdo desejado (ex: Matemática → Álgebra).
4. Toque no ícone de **Download** (↓) ao lado de cada vídeo ou seção.
5. Aguarde o download. Os vídeos ficam disponíveis offline.

## O que funciona 100% offline

- Vídeos previamente baixados
- Anotações pessoais salvas localmente

## O que NÃO funciona offline

- Exercícios e quizzes interativos
- Sincronização de progresso
- Novos downloads de conteúdo

## Conteúdo prioritário para baixar

Para um kit de sobrevivência digital, priorize:

1. **Primeiros Socorros / Biologia Humana** — informações médicas básicas
2. **Matemática Básica** — essencial para cálculos de campo
3. **Física** — eletricidade, mecânica básica

## Estimativa de espaço

Cada vídeo ocupa entre 30–150 MB dependendo da qualidade e duração. Um módulo completo pode ocupar 1–3 GB.
