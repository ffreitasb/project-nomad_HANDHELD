# Unit Converter Ultimate — Guia de Primeiro Uso

**O que é:** conversor de unidades offline completo. Cobre temperatura, peso, distância, velocidade, área, volume, frequência de rádio, pressão, energia e mais de 200 categorias.

## Primeiro uso

1. Instale pela Play Store.
2. **Não é necessária configuração** — abre e já funciona offline.
3. Selecione a categoria (ex: Frequência) → escolha as unidades de origem e destino → insira o valor.

## O que funciona 100% offline

Tudo. O app não usa internet em absolutamente nada.

## Categorias mais úteis para campo

| Categoria | Casos de uso |
|---|---|
| Temperatura | Celsius ↔ Fahrenheit ↔ Kelvin |
| Distância / Comprimento | km ↔ milhas, metros ↔ pés |
| Frequência | MHz ↔ GHz (para rádio) |
| Pressão | hPa ↔ inHg (previsão do tempo) |
| Combustível | L/100km ↔ MPG |
| Dados digitais | MB ↔ GB ↔ TB |

## Estimativa de espaço

Menos de 5 MB. Não ocupa espaço relevante.
